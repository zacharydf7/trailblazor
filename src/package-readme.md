# Trailblazor

An MIT-licensed Blazor UI component library for .NET 10: accessible by default, styled with design tokens and cascade
layers, and built on the browser's native `<dialog>` and Popover API.

The packages ship together, at one version:

- **Trailblazor**: the components, their styles and scripts, and an analyzer that checks your markup.
- **Trailblazor.Primitives**: the headless behaviors the components share.
- **Trailblazor.Testing**: bUnit setup and a driver for each component, for testing apps built with Trailblazor.
- **Trailblazor.Testing.Playwright**: Playwright helpers that find components by role and label.
- **Trailblazor.Icons.Material**: Material Symbols for `TbIcon`.

Getting started, the component pages and the guides are at [trailblazor.dev](https://trailblazor.dev/).
