# Rich text editor

Pattern: none for the editing area, which is a labeled multi-line `textbox`; its toolbar follows
[Toolbar](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/)

Familiar apps: Google Docs, Word for the web, Gmail's compose box, Outlook's message editor

## Not applicable

- Fonts, sizes and arbitrary colors: the editor keeps to its formats and links. Highlight is one marker color, the browser's own for `<mark>`, and a text color is one of the design system's tones, not an arbitrary color, so it keeps its contrast in dark mode and in every palette. A pasted background color isn't read as a highlight, since most pasted text carries its source page's background.
- Markdown-style inline shortcuts such as `**bold**`: typing them as text is common, and the toolbar and shortcuts cover the formats.
